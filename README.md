# Нейросетевой синтез фазового ДОЭ: 4 изображения на 4 расстояниях

[Презентация команды AI B2B SaaS 67 (PDF)](presentation/photon.pdf)

Нейросеть получает **4 изображения 128×128** и строит **один фазовый ДОЭ** (PNG 128×128, 8 бит, grayscale; 0 → −π, 255 → +π). При освещении лазером (λ = 532 нм, пиксель ПВМС 10 мкм) он восстанавливает изображения по расчёту дифракции Френеля одним БПФ на расстояниях **24,1 / 25,3 / 26,5 / 27,7 мм**.

## Быстрый запуск в Docker

**Для первого запуска используйте режим по умолчанию — FASTGS-100.** Дополнительные флаги, выбор чекпойнта и ручная установка библиотек не нужны.

### 1. Собрать образ

```bash
docker build -t doe-synth .
```

### 2. Запустить демо

```bash
docker run --rm -v "$PWD/out:/out" doe-synth
```

Автоматически используются встроенный комплект `shapes`, метод `nn_fastgs`, 100 итераций GS и веса `checkpoints/stage0-finetuned.pt`. Результат появится в `./out`.

| файл | содержимое |
|---|---|
| **`doe.png`** | DOE: PNG L, 128×128, 8 бит, 0 → −π, 255 → +π |
| `recon_1.png … recon_4.png` | восстановления по Френелю из сохранённого DOE: амплитуда \|K\|, нормировка на максимум |
| `metrics.json` | SSIM и Pearson по плоскостям, средние/худшие значения, время, метод и число итераций |

Для показа достаточно этой команды, четырёх восстановлений и `metrics.json`.

### Запуск своих 4 изображений

Положите в `in/` ровно четыре PNG (128×128, 8 бит, 1 канал). Порядок по алфавиту имён: `1.png … 4.png` ↔ 24,1 … 27,7 мм. Режим остаётся тем же FASTGS-100:

```bash
docker run --rm -v "$PWD/in:/in" -v "$PWD/out:/out" doe-synth --in-dir /in --out /out
```

Можно передать файлы явно:

```bash
docker run --rm -v "$PWD:/data" doe-synth /data/a.png /data/b.png /data/c.png /data/d.png --out /data/out
```

Без Docker:

```bash
pip install -r requirements.txt
DOE_DEFAULT_MODE=fastgs python predict.py --in-dir in --out out
```

## Режимы и результаты

Все режимы сохранены, но для первого запуска нужен только основной.

| режим | флаг | назначение |
|---|---|---|
| **FASTGS-100 — основной** | ничего не добавлять | stage-0 + GS-100; около **150 мс**, SSIM **0,4516**, Pearson **0,6781** на 12 демо |
| FASTGS-50 | `--fastgs --steps 50` | запасной скоростной режим: около **98 мс**, SSIM **0,4444** |
| Исходная полная сеть | `--fast` | один проход без GS; около **389 мс**, SSIM **0,3919** |
| Refine | `--refine` | полная сеть + 100 шагов Adam-уточнения |
| Quality | `--quality` | дополнительные шаги и отбор по метрикам; исследовательский режим, занимает секунды |
| Visual | `--visual` | multiscale L1 + excess-TV; исследовательский режим, занимает секунды |

FASTGS — гибрид: нейросеть создаёт начальную фазу, GS уточняет её без обучаемых параметров. На тех же 12 демо GS-200 даёт SSIM **0,4546**, Pearson **0,6825** за **202 мс**: FASTGS-100 теряет **0,67% SSIM**, но работает примерно в **1,35 раза** быстрее. Обычный GS-50 ещё быстрее (~51 мс), но его SSIM ниже (**0,4401**), поэтому мы не заявляем победу над любой классикой.

Время — медиана синтеза в Docker CPU; для FASTGS-100 выполнены три production-замера. Выброс до 264 мс сохранён в протоколе. Числа из разных режимов и наборов нельзя смешивать. [Полный протокол скорости](docs/PHOTONICS_SPEED_DEFENSE.md).

## Как это устроено

- `doe/physics.py` — дифракция Френеля одним БПФ: NumPy для оценки и дифференцируемая PyTorch-версия для обучения.
- `doe/model.py` — U-Net (11,8 млн параметров) + 6 обучаемых стадий (15,4 млн всего). Вход: 4 изображения и их обратное распространение в плоскость DOE.
- `doe/losses.py` — обучение через физическую модель: Pearson, SSIM и штраф за перекрёстные помехи.
- `doe/train.py`, `colab/train_colab.ipynb` — обучение в три этапа; основные веса — `checkpoints/best.pt`.
- `doe/data.py` — шрифты, фигуры, логотипы и открытые наборы. Train/val/test разделены по источникам, классам и шрифтам до аугментаций.
- В FASTGS используется наследованная первая стадия существующих весов; отклонённые student-модели не применяются. В CPU Docker включён `channels_last`.

Для inference внешние датасеты не нужны. Для повторения обучения требуются архивы и кэш `data/external/`; [источники, лицензии и подготовка данных](data/SOURCES.md).

## Независимая проверка

`evaluate.py` повторяет расчёт Френеля и метрики из сохранённого DOE без нейросети и torch:

```bash
python evaluate.py out/doe.png data/demo/shapes/target_1.png data/demo/shapes/target_2.png data/demo/shapes/target_3.png data/demo/shapes/target_4.png
```

Сравниваются амплитуды |K|, каждое изображение нормируется на свой максимум. SSIM и Pearson считаются по каждой плоскости и усредняются. Основной SSIM — глобальная формула из кейса; дополнительно сохраняются skimage 7×7 и Gaussian 11×11. Метрики получают из **перечитанного 8-битного PNG**.

Проверка production-пути на всех 12 демо:

```bash
docker run --rm --entrypoint python -e OMP_NUM_THREADS=4 \
  -v "$PWD/out:/out" doe-synth -m scripts.verify_fastgs_demos --steps 100 --out /out
```

Полный холодный запуск контейнера на `shapes` занял **2,17 с**: внутри программы синтез — 192 мс, весь pipeline — 350 мс. Это отдельный замер, его не нужно путать с медианой 150 мс по 12 демо.

## Архивная оценка исходной модели

На 256 отложенных комплектов старой модели `--refine` получил глобальный SSIM **0,433** и Pearson **0,560**, GS-200 — **0,375** и **0,544**. Это другой метод и другой протокол, не результат FASTGS-100. [Полный отчёт о качестве](results/jury_quality/report.md).

Изображения не безупречны: остаются спекл и перекрёстные помехи. Мы не заявляем достижение физического предела или гарантированную обобщаемость на тестах жюри.

## Исследовательские эксперименты

- **Quality:** до 300 дополнительных шагов с отбором по метрикам 8-битной фазы. На 64 отложенных комплектах исходной модели Pearson вырос с **0,5702 до 0,5773**, глобальный SSIM — с **0,4208 до 0,4287**. Это отдельный медленный режим.
- **Visual:** multiscale L1 + excess-TV. На четырёх исследовательских демо Pearson **0,6422**, глобальный SSIM **0,5415**; универсального выигрыша по всем метрикам нет.
- **Teacher→student:** созданы 512 teacher-комплектов. Student и усечённые стадии не прошли пороги качества/селективности и не используются. Ускорение 5× с сохранением качества не подтверждено.
