# Нейросетевой синтез фазового ДОЭ: 4 изображения на 4 расстояниях

Нейросеть получает **4 изображения 128×128** одного комплекта и за один вызов строит **один фазовый ДОЭ** (PNG 128×128, 8 бит, grayscale; пиксель 0 → −π, 255 → +π). Фазовая маска при освещении лазером (λ = 532 нм, пиксель ПВМС 10 мкм) восстанавливает изображения по расчёту дифракции Френеля одним БПФ на расстояниях **24,1 / 25,3 / 26,5 / 27,7 мм** (i-е изображение — на i-м расстоянии).

## Запуск в Docker (ничего устанавливать вручную не нужно)

```bash
docker build -t doe-synth .
```

Демонстрационный комплект из репозитория (результат появится в `./out`):

```bash
docker run --rm -v "$PWD/out:/out" doe-synth
```

**Свои 4 изображения.** Положите в папку `in/` ровно четыре PNG (128×128, 8 бит, 1 канал); порядок — по алфавиту имён, т.е. `1.png … 4.png` ↔ 24,1 … 27,7 мм:

```bash
docker run --rm -v "$PWD/in:/in" -v "$PWD/out:/out" doe-synth --in-dir /in --out /out
```

Или файлами по порядку: `docker run --rm -v "$PWD:/data" doe-synth /data/a.png /data/b.png /data/c.png /data/d.png --out /data/out`.

**Результат** в `out/`:

| файл | что |
|---|---|
| **`doe.png`** | **ДОЭ**: PNG 128×128, 8 бит, grayscale, 0 → −π, 255 → +π |
| `recon_1.png … recon_4.png` | восстановления по расчёту Френеля из `doe.png` (амплитуда \|K\|, нормировка на максимум) |
| `metrics.json` | Pearson и SSIM по каждой плоскости, среднее/худшая, время |

Режимы:
- **основной (по умолчанию)** — нейросеть + 100 шагов уточнения фазы тем же дифференцируемым оператором Френеля; ~3–6 с на CPU;
- **`--fast`** — только нейросеть, один прямой проход, без итераций; ~0,1–0,3 с на CPU (на GPU Mac 24 мс).

Время и качество подробнее — ниже. Без Docker: `pip install -r requirements.txt && python predict.py --in-dir in --out out`.

## Как это устроено

- `doe/physics.py` — Френель одним БПФ: `K = FFT(H·exp(jπ(u²+v²)/λz))` (центрированная сетка, унитарное БПФ; внешние множители не влияют на амплитуду после нормировки). NumPy-версия для оценки и дифференцируемая PyTorch-версия для обучения.
- `doe/model.py` — U-Net в плоскости ДОЭ (11,8 млн параметров) + **6 обучаемых стадий уточнения** (обучаемый аналог Gerchberg–Saxton; всего 15,4 млн параметров). Вход сети: 4 изображения и они же, точно распространённые назад в плоскость ДОЭ.
- `doe/losses.py` — обучение **без учителя**: фаза → расчёт Френеля → сравнение с целями **теми же метриками, что у жюри** (Pearson, SSIM; амплитуда |K|, каждое изображение нормируется на свой максимум) + **штраф за перекрёстные помехи**, который не даёт сети выдавать одну и ту же «смесь» всех 4 картинок во всех плоскостях.
- Обучение: `doe/train.py`, `colab/train_colab.ipynb` (Google Colab, L4). Три этапа: база → со штрафом за помехи → 6 стадий. Веса: **`checkpoints/best.pt`** (отбор по валидации).
- Данные для обучения: генератор `doe/data.py` — шрифты, фигуры, логотипы + открытые наборы (Caltech-101/256, Oxford Flowers-102, DTD, BSDS500, Fashion-MNIST); источники и лицензии — `data/SOURCES.md`. Разделение train/val/test **по источникам** (классам объектов и шрифтам), а не по аугментациям.
- `evaluate.py` — независимая проверка по одному `doe.png` (без нейросети и torch): повторяет расчёт Френеля и метрики.

```bash
python evaluate.py out/doe.png t1.png t2.png t3.png t4.png     # метрики из сохранённого PNG ДОЭ
```

## Протокол оценки, который мы считаем (по ответам экспертов)

Сравниваются **амплитуды |K|**, каждое изображение (исходное и восстановленное) нормируется так, что максимум = 1; Pearson и SSIM считаются по каждой плоскости и усредняются. SSIM: формула слайда (глобальная, `ssim_global`); дополнительно считаем оконные варианты (skimage 7×7, гауссово 11×11), так как реализация жюри неизвестна. Метрики считаются по **перечитанному 8-битному PNG** ДОЭ.

## Результаты (TEST: 256 комплектов с классами объектов и шрифтами, не встречавшимися при обучении; среднее и 95% bootstrap-ДИ)

| режим | SSIM (слайд, глоб.) | SSIM skimage 7×7 | SSIM gauss 11×11 | Pearson ср. | Pearson худш. плоск. |
|---|---|---|---|---|---|
| быстрый: сеть, 1 проход | 0,342 [0,331; 0,353] | 0,192 | 0,192 | 0,511 [0,501; 0,522] | 0,442 |
| **основной: сеть + 100 шагов** | **0,433 [0,421; 0,444]** | **0,299** | **0,304** | **0,560 [0,550; 0,569]** | **0,478** |
| GS-200 (классика, для сравнения) | 0,375 [0,362; 0,388] | 0,210 | 0,210 | 0,544 [0,531; 0,557] | 0,291 |

Время на один комплект: сеть — 24 мс (GPU Apple M3 Pro), ~100–250 мс (CPU); основной режим — ~0,2 с на GPU, несколько секунд на CPU; GS-200 на CPU — ~1 с, Adam-1000 — 10–20 с.

Что важно: изображения **не безупречны** — плоскости расположены через 1,2 мм при глубине резкости ≈ 0,75 мм, поэтому в каждой плоскости есть зернистость (спекл) и слабые следы соседних изображений; это физический предел для одной фазовой маски 128×128, а не особенность модели. Мы измеряем его отдельно («селективность по глубине» — разность корреляции с «своей» и «чужими» целями): у основного режима 0,26, у GS-200 — 0,20.

Все цифры воспроизводятся скриптами из `results/` и `scripts/` (подробности — `PLAN.md`, `BACKLOG.md`, `results/ml/summary.md`).

## Структура

```
predict.py            точка входа (Docker и локально)
synth.py, evaluate.py CLI синтеза со всеми методами / независимая проверка
doe/                  физика, модель, потери, обучение, данные, метрики
checkpoints/best.pt   обученные веса (основная модель, 62 МБ)
colab/                блокнот обучения в Google Colab
data/demo/            12 демонстрационных комплектов; data/SOURCES.md — источники данных
results/              таблицы и рисунки; results/final/index.html — галерея результатов
presentation/         презентация для защиты
tests/                тесты (pytest)
Dockerfile, requirements.txt
```
