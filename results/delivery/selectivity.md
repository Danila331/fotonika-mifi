# Селективность по глубине на демо-наборах

ДОЭ — `checkpoints/best.pt`; для каждого набора строится матрица 4×4: КК исходного изображения i с восстановленной амплитудой в плоскости j (протокол экспертов: |K|, нормировка на максимум). **Селективность** = среднее по диагонали − среднее вне диагонали: насколько восстановление в своей плоскости похоже на «своё» изображение сильнее, чем на соседние. ДОЭ, который во всех плоскостях рисует одну и ту же смесь, даёт ≈ 0. «Своя лучшая» — в скольких из 4 плоскостей восстановление больше всего похоже именно на свою цель. «Сходство целей» — средний КК между самими исходными изображениями: у похожих целей (четыре ракеты, четыре цифры одного шрифта) КК вне диагонали высокий при любом ДОЭ.
