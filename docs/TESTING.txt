2️⃣ Формат сдачи решений

Каждой команде необходимо предоставить GitHub-репозиторий с возможностью запуска решения в Docker-контейнере.

В репозитории должны присутствовать:
1. Исходный код нейросети.
2. Обученные веса модели.
3. Dockerfile для сборки контейнера.
4. requirements.txt со списком зависимостей.
5. README.md с инструкцией по сборке и запуску.

Важно: решение должно запускаться в Docker без необходимости ручной установки библиотек и дополнительной настройки окружения.

3️⃣Требования к тестированию

Для проверки качества работы моделей будет использоваться не менее 5 комплектов тестовых изображений

• Каждый комплект состоит из 4 изображений размером 128×128 пикселей.
• В комплектах будут представлены различные типы объектов.
• Модель должна совместно обработать 4 изображения одного комплекта и сгенерировать один фазовый ДОЭ.

Требования к выходному файлу:
• Формат: PNG.
• Размер: 128×128 пикселей.
• Глубина цвета: 8 бит.
• Цветовой формат: Grayscale (оттенки серого).

После получения ДОЭ будет выполнен расчёт дифракции Френеля на четырёх заданных расстояниях. Полученные восстановленные изображения будут использоваться для оценки качества работы модели.

4️⃣ Критерии оценки решений

Для оценки качества восстановления изображений будут использоваться две метрики:
• SSIM — основная метрика оценки структурного сходства изображений.
• Pearson — дополнительная метрика оценки корреляции между изображениями.

Для каждого тестового комплекта обе метрики рассчитываются отдельно для каждого из четырёх восстановленных изображений, после чего усредняются.

По итогам тестирования для каждой команды будут сформированы результаты по каждому комплекту и итоговые средние значения по всем комплектам.

Дополнительно: будет фиксироваться время работы модели, поскольку одна из целей задачи — ускорение синтеза ДОЭ.
